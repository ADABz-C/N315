# N315 Homework 1 | Overview

## Introduction

This assignment introduces the fundamentals of Sass and the BEM (Block, Element, Modifier) methodology for building more organized, scalable, and maintainable CSS. You will learn how Sass improves the styling workflow and how BEM helps create consistent, readable class naming patterns for web pages.

To complete this assignment, review the BEM guide at [CSS-Tricks: BEM 101](https://css-tricks.com/bem-101/). You may also research the topic through additional sources if needed. The goal is to understand the concept and apply it thoughtfully in your work.

## Learning Objectives

By the end of this assignment, you should be able to:

- explain what Sass is and why it is useful in front-end development
- describe the BEM naming system and how it improves CSS organization
- recognize the benefits of structured styling for maintainability and scalability
- apply these concepts to improve the design and structure of your homework project

## Assignment Expectations

- review Sass concepts and how they support modular styling
- understand the purpose of BEM and its role in modern CSS architecture
- apply the principles to your project structure and styling decisions
- write code that is clear, reusable, and easy to maintain

## Why This Matters

Learning Sass and BEM is important because they help developers write cleaner, more efficient CSS. These practices make styling easier to manage as a project grows and help create more consistent user interfaces.

This assignment is designed to strengthen your foundation in front-end development and prepare you for more advanced styling work in future projects.
