# Summit Ridge Outfitters

A front-end website project for a fictional outdoor outfitter. The site includes a contact page with a message form, store information, hours, FAQs, and shared navigation and footer elements.

## Run the project

Open the `Homework5` folder in VS Code and launch `index.html` with the **Live Server** extension. Serving the site locally is recommended because the project uses JavaScript modules.

## Project structure

- `index.html` — main page markup
- `css/` — stylesheets
- `images/` — page images
- `src/` — main JavaScript and authentication code
- `pages/` — page modules
- `components/` — reusable navigation, footer, and other UI components
- `utils/` — form feedback and validation utilities

## Notes

Some links and form actions use `#` placeholders and may not navigate or submit data yet. Update them when the corresponding pages or functionality are ready.
