# USER-FEEDBACK

This folder is dedicated to documenting user feedback for the N315 project. It serves as a place to collect comments, suggestions, issues, and review notes that help improve the project during development.

## Purpose

The purpose of this folder is to keep all user-centered feedback organized and easy to reference. By recording what users experience, the project team can identify areas that need improvement and make changes based on real input.

## What is Included

This folder may contain:

- feedback summaries
- bug reports or usability concerns
- feature requests
- notes from reviews or testing
- recommendations for improvements

## Project Context

N315 is a project repository used for coursework or development work on the `hw3` branch. The use of a dedicated feedback folder helps track how project decisions evolve through iteration and revision.

## Goal

The goal of the feedback process is to improve the project based on user needs and observations, making the final result more effective, usable, and aligned with expectations.
